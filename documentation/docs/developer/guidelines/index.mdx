These pages are the conventions of the project. Follow them in every change, and review pull requests against them.

| Page | Covers |
|---|---|
| [Java](/developer/guidelines/java) | Package structure, naming, Spring beans, DTOs, errors, Javadoc |
| [Server and API Design](/developer/guidelines/server-design) | Route prefixes, where server code belongs, DTO rules |
| [TypeScript and Angular](/developer/guidelines/typescript-angular) | Components, signals, templates, types, API services |
| [Styling and Theming](/developer/guidelines/client-styling-theming) | SCSS structure, colors, responsive layout |
| [Testing](/developer/guidelines/testing) | Server and client tests, checks before a pull request |
| [Writing Documentation](/developer/guidelines/documentation) | How to write and build pages of this site |

A convention changes in a pull request like any code change. When you change one, update its page in the same pull
request, so that this site stays the single place where the conventions are written down.
