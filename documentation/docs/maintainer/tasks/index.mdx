## Routine work

The poller runs twice a week. After each scheduled run, open the **Actions** tab and check the **Artemis delivery
poller** run:

- When it passed and opened a delivery pull request, [review it](/maintainer/tasks/review-delivery-pr).
- When it passed without a pull request, nothing changed since the last delivery.
- When it failed, [fix the run](/maintainer/tasks/fix-failed-extraction) before the next one.

## On-demand work

Everything else comes up when something changes: a new Artemis feature that teachers should be able to choose, a
change in the Artemis source layout, a new version of the Ansible collection, or an image that you want to approve or
replace.
